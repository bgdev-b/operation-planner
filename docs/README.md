# Visual Assets Guide

Use this folder to store portfolio media used by the root `README.md`.

## Folder Layout

- `docs/media/01-home-resources.png`
- `docs/media/02-resource-detail-overview.png`
- `docs/media/03-create-drag-assignment.png`
- `docs/media/04-assignment-actions.png`
- `docs/media/planner-flow.mp4`

## Capture Recommendations

- Keep one browser size for every screenshot (for example, `1440x900`).
- Hide personal browser UI elements (bookmarks, profile icon, extra tabs).
- Record a short 8-12 second MP4 showing: select range, create task, move/resize, delete.
- Keep file names exactly as listed above so README links work without edits.
